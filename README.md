In the ./installation/ folder execute the two .exe files
i) `python-3.11.4-amd64.exe`
ii) `rustup-init.exe`

Open your web browser and paste the contents of the file `ffmpeg-installation-path.txt`
A .zip file will be downloaded
Extract the files to a secured folder
Copy the full path of the `./ffmpeg-8.1.1-essentials_build/bin` folder
Add this path to your Path variables in Environment
